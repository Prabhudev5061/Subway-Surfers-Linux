# SubwaySurfers-SanFrancisco-Linux

- **Game Build:** Subway Surfers World Tour: San Francisco (`1.94.0`)
- **Unity Engine:** `2019.4.18f1` (`Build/SanFrancisco.json`)
- **Electron Runtime:** Electron `36.5.0` / Chromium `134`
- **Upstream Foundation:** Original Linux AppImage by Drizzle (`https://www.appimagehub.com/p/2299024`)
- **Shared Save Location:** `~/.local/share/SubwaySurfers-Linux/Save/`
- **Original Logo:** `Source/SanFrancisco/assets/subwaysurfers.png` (`512x512` RGBA, SHA-256 `95ea7b903bf206b293c1f2fcfcbcfc40d3e6391c78fbbec4672c360b5fb694c3`)

## Overview
Preserves the original San Francisco WebGL build, minimal full-viewport loading and gameplay UI, fullscreen startup (`F11` toggle, `Escape` preserved), and event-driven AutoSave while upgrading runtime security and migrating persistence to the unified shared `Save/` directory.
